# Area Library

## Overview

AreaLibrary - is a C# library for external clients that allows you to easily calculate the area of ​​a circle given its radius and the area of ​​a triangle given its three sides. The library also includes additional features such as the ability to add other shapes and to check whether a triangle is a right triangle.

## Features

-Adding new figures

-Creating a figure just with the parameters
